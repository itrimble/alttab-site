Features

Everything needed for a focused Mac switcher.

The feature set is grounded in the current app architecture and avoids promises that require unshipped services or private APIs.

Configurable shortcuts

Option+Tab is the default. Control+Tab and Option+Space are supported alternatives, with shortcut settings built into the native command center.

Release-to-switch behavior

Hold the modifier, tap the trigger key to move selection, and release the modifier to activate the highlighted app or window.

Visual switcher modes

Choose thumbnail, app-icon, or title-focused layouts with sizing controls for different monitors and workflows.

ScreenCaptureKit thumbnails

When Screen Recording is granted, the app uses public ScreenCaptureKit capture paths for local window previews.

Grouped window thumbnails

Apps with several windows can show nested thumbnail targets, with wheel and trackpad paging for fast per-window selection.

App exceptions

Hide selected apps from the switcher or suppress the global shortcut when matching apps are active.

Launch at login

Uses the public ServiceManagement flow so the menu bar utility can start automatically when enabled.

Guided onboarding

Explains required, optional, and unnecessary permissions before sending users to macOS Settings.

Diagnostics

Local logs and copyable diagnostics help support issues without requiring Xcode or remote telemetry.

Native settings

The status menu and Settings window share the same model-backed configuration for consistent behavior.
